# Salon Booking App

A minimal React + Vite + Tailwind CSS application for salon appointment booking.

## Stack

- React 19
- Vite
- Tailwind CSS
- React Router

## Getting started

```bash
npm install
npm run dev
```

## Project structure

```
src/
├── assets/
├── components/
├── hooks/
├── pages/
├── services/
└── utils/
```

## Routes

| Path | Page |
|------|------|
| `/` | Welcome |
| `/calendar` | Calendar |
| `/booking` | Booking Form |
| `/confirmation` | Confirmation |
